Presentació

Aquest projecte transforma el codi base TimberSFML3.cpp resolent 9 reptes que treballen variables i conversions (RA1), estructures de control i excepcions (RA3), entrada/sortida i fitxers (RA5) i tipus avançats com arrays, structs i vectors (RA6).

Els 9 reptes

1. Recursos propis amb càrrega segura
2. Més NPC (abelles i núvols)
3. Bosc d'arbres amb struct i vector
4. Vides + panell semitransparent
5. Indicador d'FPS (static_cast)
6. Branques en un vector d'structs
7. Dos modes de joc (enum + switch)
8. Rècord persistent en fitxer
9. Excepcions, assert, break/continue
